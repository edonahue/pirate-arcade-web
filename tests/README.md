# Pirate Arcade Tests

This directory contains tests for the Pirate Arcade website.

## Test Structure

- `unit/` - Unit tests for individual components/utilities
- `integration/` - Integration tests for game flows
- `e2e/` - End-to-end tests for critical user journeys

## Running Tests

Currently, no test runner is configured. This is a placeholder to establish testing hygiene.

To add tests:
1. Choose a testing framework (Vitest, Jest, Playwright, etc.)
2. Add configuration
3. Implement tests in appropriate subdirectories
