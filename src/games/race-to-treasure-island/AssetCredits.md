# Asset Credits — Race to Treasure Island

All visual and audio assets for this game are self-generated or CC0.

## Visual Assets

- **Ship sprites, obstacles, UI elements:** Programmatically generated using Phaser Graphics API at boot time. No external image files.
- **Ocean/ocean effects:** Procedural via Phaser shader-like tiling and tinting.
- **Font:** System monospace for UI; pirate-themed text via Phaser text style.

## Sound

- **No audio in MVP.** Audio may be added in a future iteration using Phaser's Web Audio API for procedural sound effects (waves, cannon, coin pickup).
